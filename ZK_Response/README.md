# ZK_Response Module

Standalone Zero-Knowledge Proof (ZKP) module designed to intercept and evaluate fraud payloads generated by the Attacker AI agent.

## Structure
- `src/main.nr`: Noir circuit enforcing bounds & risk score thresholds.
- `contracts/CustomsEscrow.sol`: EVM contract performing on-chain proof verification.
- `scripts/zk_bridge.py`: Python bridge connecting Defender AI risk outputs to Noir execution.
- `scripts/test_proof.ts`: Smart contract deployment and verification test script.

## Setup & Usage
1. Install Noir: `nargo --version`
2. Run circuit check: `nargo check`
3. Execute Python response handler: `python3 scripts/zk_bridge.py`
